# Wi-Fi 无法连接或控制页面打不开

## 正常连接方式

1. 给赤道仪接入 USB-C 5V 电源，电源能力至少 1A。
2. 等待设备启动，在手机 Wi-Fi 列表中选择 `OG Star Tracker`。
3. 忽略“此网络无互联网连接”的提示并保持连接。
4. 在浏览器地址栏输入 `http://tracker.local`，不要在搜索框中搜索该地址。

## 逐项排查

1. 关闭手机移动数据、VPN，以及“自动切换到更佳网络/蜂窝网络”。
2. 忘记该 Wi-Fi 后重新连接。
3. 关闭浏览器的强制 HTTPS 功能，确认使用的是 `http://`。
4. 更换 USB-C 线缆和可靠的 5V 电源，重新上电。
5. 用另一台手机或电脑连接，区分设备端和手机端问题。
6. 若能连接 Wi-Fi 但页面仍打不开，记录手机型号、系统版本、浏览器、指示灯状态和故障出现时间，再联系支持。

## 不要做什么

- 不要为了“增强信号”提高供电电压。
- 不要在没有对应版本固件和恢复办法时随意刷写固件。
- 不要把设备 Wi-Fi 的“无互联网”提示误认为硬件必然故障。
