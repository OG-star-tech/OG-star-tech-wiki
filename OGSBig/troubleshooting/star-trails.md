# 星点拉线、模糊或跟踪方向异常

星点问题通常来自跟踪方向、极轴、机械稳定性、相机振动或曝光参数。建议一次只改变一个条件。

## 快速判断

1. 检查控制界面所选半球是否正确。若跟踪方向相反，星点会快速拉线。
2. 将焦距和曝光时间降到原来的一半进行测试。
3. 确认三脚架、赤道仪、球头、相机和镜头全部锁紧。
4. 重新对极轴；长焦优先使用极轴镜或漂移法。
5. 检查负载重心是否过高、是否明显偏向一侧，以及线缆是否拉扯相机。
6. 使用快门预延时、电子前帘或遥控快门，减少按键和反光板振动。

## 根据星点表现排查

| 表现 | 优先检查 |
| --- | --- |
| 每张都向同一方向明显拉长 | 半球方向、是否启动跟踪、极轴偏差 |
| 部分照片清晰、部分抖动 | 风、地面振动、三脚架、快门振动、线缆 |
| 画面中心较清晰、边缘呈放射状 | 镜头像差、光圈和对焦，而不一定是跟踪问题 |
| 曝光越长拉线越明显 | 极轴精度、周期误差、焦距与像素尺度 |
| 设备有卡滞或异常声音 | 立即停止并断电，检查机械干涉和负载 |

## 提交问题时建议提供

- 镜头焦距、相机型号和曝光时间。
- 负载总重量及安装照片。
- 所在半球和对极轴方法。
- 一张原始星点照片及 100% 放大截图。
- 当时风况、地面和三脚架情况。
