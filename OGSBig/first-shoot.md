# 第一次拍摄

本流程用于完成第一次星野跟踪拍摄。首次使用建议选择较短焦距和较短曝光，确认方向、极轴与稳定性后再逐步增加难度。

## 1. 安装设备

1. 将赤道仪直接安装到稳固三脚架上，尽量不要在赤道仪下方叠加球形云台。
2. 在赤道仪顶部安装球头，再安装相机和镜头。
3. 调整构图前确认所有连接螺纹和锁紧旋钮可靠。
4. 使用 USB-C 5V 电源供电，电源输出能力至少 1A。

## 2. 调整纬度并对极轴

1. 按所在地纬度选择正确的弧板和旋钮孔位，参见[纬度调节](/OGSBig/Latitude_adjustment)。
2. 让极轴大致指向北天极或南天极。
3. 根据现场条件使用极轴镜、激光、手机辅助或漂移法完成校准。
4. 调整完成后锁紧纬度和方位机构。

极轴镜通常能获得更高精度；激光更方便但不得在机场或禁用区域使用；手机辅助适合看不到北极星、接近赤道或南半球等场景，说明书建议用于 100 mm 以下焦距的入门拍摄。

## 3. 连接控制界面

1. 在手机 Wi-Fi 设置中连接 `OG Star Tracker` 网络。
2. 手机提示“无互联网连接”属于正常现象；如页面无法打开，可暂时关闭移动数据和自动切换网络功能。
3. 在浏览器访问 `http://tracker.local`。
4. 选择所在半球，并选择 Sidereal（恒星）跟踪速度。
5. 启动跟踪，观察设备运行方向是否正确。

## 4. 第一次曝光

1. 建议从 50–100 mm 焦距、10–30 秒曝光开始。
2. 放大检查星点。如果星点拉线，先检查三脚架、跟踪方向、极轴和相机抖动。
3. 确认星点正常后，再逐步增加焦距或曝光时间。
4. 使用 2.5 mm 快门线时，可在间隔拍摄器中设置曝光时间、张数、拍摄间隔和预延时。

说明书中的曝光时间表来自特定测试条件，只能作为参考，不能保证每套相机、焦距、风况和负载都达到相同结果。

## 5. 拍摄结束

1. 停止间隔拍摄和跟踪。
2. 关闭相机并断开赤道仪电源。
3. 先卸下相机和球头负载，再折叠或切换旅行模式。
