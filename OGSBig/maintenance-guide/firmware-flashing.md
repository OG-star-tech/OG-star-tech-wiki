# 固件烧录教程
> 最新固件已支持OTA，但由于目前下载源在Github，部分用户可能更新失败，此时可选择手动更新。
{.is-info}


## 1. 获取固件文件
您可以通过以下任一方式获取固件：
- **备用下载**：从百度网盘下载预先编译的固件文件(可能更新不及时，但是访问方便)
  🔗 [下载链接](https://pan.baidu.com/s/1arHrrzlvskoo9K62B3_e4w?pwd=ogst)  
- **自行编译**：访问 GitHub 仓库获取源代码并自行编译（实时更新，选择包含引导的固件，需要能访问github）
  🔗 [下载链接(Github)](https://github.com/OG-star-tech/OG-star-tracker-/releases)  


## 2. 下载烧录工具
请下载 `flash_download_tool` 烧录工具：
- **官方渠道**：  
  🌐 [乐鑫官方下载页面](https://www.espressif.com/zh-hans/support/download/other-tools)  
- **备用渠道**：  
  🔗 [百度网盘下载](https://pan.baidu.com/s/1arHrrzlvskoo9K62B3_e4w?pwd=ogst)  
  （包含“软件、固件”文件夹）

## 3. 配置烧录参数
1. 打开烧录工具，按下图所示进行配置：
   ![步骤1.png](/教程/烧录/步骤1.png)
   ![步骤2.png](/教程/烧录/步骤2.png)
2. 选择已下载的固件文件，并按图示完成参数设置：
   ![步骤3.png](/教程/烧录/步骤3.png)
   

## 4. 连接设备
1. 准备一条**可传输数据**的 USB 数据线
2. 将数据线一端连接电脑，另一端连接赤道仪主板的 Type-C 接口
   - 如赤道仪主板有多个 Type-C 接口，请选择**数据输入口**
3. 打开计算机的**设备管理器**，确认设备被识别并记录对应的 COM 端口号
	>PS：如果您的设备没有显示带有CH340标识的设备，可能是因为缺少CH340驱动，可自行[下载CH340驱动](https://www.wch.cn/products/CH340.html)安装，安装后请重启电脑后继续。
  
   ![步骤4.png](/教程/烧录/步骤4.png)

## 5. 开始烧录
1. 点击 **START** 按钮开始烧录（务必确认已勾选固件文件地址前的对号，此时固件地址显示为绿色）
2. 等待烧录进度完成，期间请勿断开连接
![步骤5.png](/教程/烧录/步骤5.png)

## 6. 完成验证
当界面显示“完成”提示时，即表示固件已成功烧录。此时可安全断开设备连接。

![步骤6.png](/教程/烧录/步骤6.png)
---
*注意：烧录过程中如遇异常，请检查数据线连接稳定性并重新尝试。*
