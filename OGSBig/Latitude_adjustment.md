# 欧极星赤道仪纬度调节

设备通过纬度弧板、顶部/底部旋钮孔位和纬度调节杆改变极轴高度。安装相机负载前，应先选择正确结构并完成锁紧。

## 选择纬度弧板

- 标准弧板：25°–90°。
- 低纬弧板：0°–25°。所在地纬度低于 25°时使用。

## 标准 25°–90° 弧板的孔位

| 目标纬度 | 旋钮孔位 |
| --- | --- |
| 90°–60° | 顶部孔位 |
| 60°–55° | 顶部或底部均可，选择调节余量更合适的一侧 |
| 55°–25° | 底部孔位 |
| 旅行模式 | 必须使用顶部孔位 |

> 说明书原文以重叠范围表达：顶部孔约用于 90°–55°，底部孔约用于 60°–25°，55°–60°均可。表格将其整理为不重叠的快速选择区间。

## 调节步骤

1. 卸下或扶稳相机负载，松开纬度锁紧旋钮。
2. 根据所在地纬度选择弧板和孔位。
3. 转动纬度调节旋钮，让极轴接近目标高度。
4. 配合方位调节完成极轴校准。
5. 拧紧纬度与方位锁紧机构，确认没有松动后再开始拍摄。

如果调节到行程末端仍无法达到目标纬度，不要强行拧动，应检查弧板、孔位和安装方向是否正确。
