# 欧极星赤道仪供电指南

## 电源要求

- 接口：USB-C
- 输入电压：5V
- 电源输出能力：至少 1A
- 推荐电源：质量可靠的 5V 移动电源或稳压电源

> 请勿使用会向设备输出 9V、12V 或更高电压的非兼容供电方案。USB-C 外形相同不代表输出电压一定适合本设备。

## 上电前检查

1. 确认相机、球头和赤道仪安装牢固。
2. 确认纬度和方位调节机构已经锁紧。
3. 确认电源标称输出为 5V，且可持续提供至少 1A。
4. 插入 USB-C 线缆，等待设备启动并广播 Wi-Fi。

## 无法启动时

1. 更换一根确认可传输电源的 USB-C 线。
2. 更换 5V/1A 或更高电流能力的电源；“更高电流能力”不等于提高电压。
3. 断开相机快门线等附件，仅保留赤道仪供电后测试。
4. 若仍无响应，不要拆机带电测试，请联系售后并记录电源型号、线缆和指示灯状态。
