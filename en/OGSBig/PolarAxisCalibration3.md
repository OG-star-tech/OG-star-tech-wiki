# Mobile polar alignment instructions (the most convenient way)

smartphone polar alignment is the **simplest and most convenient** polar alignment method, suitable for rapid deployment and wide-angle shooting.

# Applicable scenarios

Recommended:

* Focal length ≤ 100mm
* Unable to observe Polaris
* Areas close to the equator
* Southern Hemisphere environment
* For beginners

Accuracy:

Below laser with polar scope method

---

# Required tools

Requires:

* Mobile phone holder (included)
* Mobile application

Recommended apps:

* **Polar Scope Align Pro**
* **Stellarium**

---

# Operation steps

# # 1. Install the mobile phone holder

Will:

**Mobile phone holder inserts into the back of the tracker**

Make sure:

Fixed firmly
No shaking

---

# # 2. Install mobile phone

Secure the phone to the holder.

Start:

Polar alignment applications.

---

# # 3. Start the alignment function

The application will:

Automatically identify Current Position
Calculate North or South Celestial Pole direction

and displays:

Target direction hints.

---

# # 4. Adjust tracker direction

by:

* latitude adjustment
* Azimuth adjustment

Mobile Tracker:

Until the application prompts:

**Alignment completed**

---

# Usage suggestions

Recommended:

* Wide-angle star field
* Travel photography
* Rapid deployment

Not recommended:

* Telephoto lens
* Deep space photography
