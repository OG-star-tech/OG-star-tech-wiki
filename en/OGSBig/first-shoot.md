# first shoot

This process is used to complete the first starfield tracking shooting. For first-time users, it is recommended to choose a shorter focal length and shorter exposure, and then gradually increase the difficulty after confirming the direction, polar axis and stability.

# # 1. Install the device

1. Install the equatorial mount directly on a stable tripod, and try not to stack a ball head underneath the equatorial mount.
2. Install the ball head on the top of the equatorial mount, and then install the camera and lens.
3. Confirm that all connecting threads and locking knobs are reliable before adjusting the composition.
4. Use a USB-C 5V power supply with a power output capacity of at least 1A.

# # 2. Adjust latitude and polar alignment

1. Select the correct arc plate and knob hole position according to your location
2. Let the polar axis point roughly toward the North or South Celestial Pole.
3. Complete calibration using polar scope, laser, mobile phone assistance or drift method according to on-site conditions.
4. After the adjustment is completed, lock the latitude and the azimuth mechanism.

polar scope usually achieves higher accuracy; laser is more convenient but should not be used in airports or prohibited areas; mobile phone assistance is suitable for scenes such as when the North Star cannot be seen, close to the equator or the southern hemisphere, and the manual recommends it for entry-level shooting with a focal length below 100 mm.

# # 3. Connect to the control interface

1. Connect to the `OG Star Tracker` network in your phone’s Wi-Fi settings.
2. It is normal for the mobile phone to prompt "No Internet connection"; if the page cannot be opened, the mobile data and automatic network switching functions can be temporarily turned off.
3. Access `http://tracker.local` in the browser.
4. Select your hemisphere and select the Sidereal tracking speed.
5. Start tracking and observe whether the equipment is running in the correct direction.

# # 4. First exposure

1. It is recommended to start with a focal length of 50–100 mm and an exposure of 10–30 seconds.
2. Zoom in to check the star point. If the star point is pulled, first check the tripod, tracking direction, polar axis and camera shake.
3. After confirming that the star point is normal, gradually increase the focus or exposure time.
4. When using a 2.5 mm shutter release, you can set the exposure time, number of shots, shooting interval and pre-delay in the interval shooter.

The exposure schedule in the instruction manual is derived from specific test conditions and can only be used as a guide. It does not guarantee that every set of cameras, focal lengths, wind conditions and loads will achieve the same results.

# # 5. End of shooting

1. Stop interval shooting and tracking.
2. Turn off the camera and disconnect the equatorial mount from power.
3. Remove the camera and ball head load first, then fold or switch to travel mode.
