# 1. Laser polar alignment instructions (quick alignment)

![ishot_2026-04-11_22.38.29.png](/ogs赤道仪v/ishot_2026-04-11_22.38.29.png)

Laser polar alignment is an **easy-to-use, relatively accurate method** suitable for most wide-angle to medium-focal-length imaging.

**Note: The use of laser equipment is generally prohibited near airports, please comply with local regulations.**

---

# Applicable scenarios

Applies to:

* Lenses with focal length ≤ 200mm
* Need to complete alignment quickly
* Can observe Polaris (Northern Hemisphere) or South Celestial Pole reference area
* When polar scope is not available or polar scope is not available

Accuracy:

Higher than smartphone alignment
Below polar scope with drift method

---

# Operation steps

# # 1. Unlock the adjustment mechanism

Before performing polar alignment:

1. Unscrew the **latitude adjustment knob**
2. Rotate the knob for **up-and-down angle adjustment**.

If you need to adjust left and right:

1. Unscrew the **azimuth adjustment knob**
2. Adjust left and right directions
3. Tighten the second knob again

Make sure:

* Smooth adjustment process
* All knobs are finally locked

---

# # 2. Install laser

Secure the laser to:

**Polar axis installation position**

Make sure:

* The laser axis is coaxial with the tracker polar axis
* The laser is firmly fixed

---

# # 3. Aim at the North Celestial Pole (Northern Hemisphere)

In the Northern Hemisphere:

Point the laser at:

**Polaris**

For higher precision:

Don't point directly to the center of Polaris, but instead:

**Slightly Off Polaris**

Reason:

The North Celestial Pole (NCP) is not at the exact center of Polaris, but is slightly offset.

---

# # 4. Precise offset method (recommended)

The true North Celestial Pole position can be determined using the following astronomical software:

* **Stellarium**
* **Cartes du Ciel**

According to the software prompts:

Fine-tune laser pointing:

**The true position of the North Celestial Pole**

---

# # 5. Southern Hemisphere Operations

In the Southern Hemisphere:

Need to refer to:

**South Celestial Pole (SCP) Star Map**

Since there are no obvious bright stars in the south celestial pole:

It is recommended to cooperate with astronomical software to complete positioning.

---

# Usage suggestions

Recommended:

* For wide angle and medium focus shooting
* Quickly set up scenes
* Travel photography

Not recommended:

* Telephoto photography (≥300mm)
* Super long exposure shooting
