# OG Star TrackerHow to fold


# # 1. Overview of functional mode
This tracker supports two core usage modes, which can be flexibly selected according to the usage scenario (home/travel) to meet the usage needs in different scenarios.

# # 2. Still mode

![ishot_2026-04-11_21.59.00.png](/ogs赤道仪v/ishot_2026-04-11_21.59.00.png)
## # 1. Installation method
Fix the tracker latitude rod in place through the rod fixing piece, ensuring that the latitude rod is not loose or displaced.
## # 2. Applicable scenarios
It is suitable for non-traveling scenarios with ample space, and is especially suitable for fixed use at home to ensure the stability and effectiveness of the tracker.

# # 3. Travel mode
![ishot_2026-04-11_21.59.05.png](/ogs赤道仪v/ishot_2026-04-11_21.59.05.png)
## # 1. Installation method
- Fixed logic: In this mode, the latitude rod does not use rod clamps to fix it, and only relies on magnets to maintain its position;
- Unfolding for use: the illustration shows the folded transport position. **Important:** after unfolding, the latitude rod is held only by magnets. Confirm that the magnet polarities are aligned and fully tighten the latitude knob before completing the installation.
- Folding and storage: The latitude rod can be inserted into the base and fixed with magnets; if you need to enhance the stability, you can use additional cable ties to assist in fixing.

## # 2. Applicable scenarios
- Core scenes: travel shooting scenes, the folded volume is smaller than the static mode, making it easy to carry and store;
- Expand the scene: When you need to use the time-lapse photography function to create time-lapse videos, this mode is preferred.
