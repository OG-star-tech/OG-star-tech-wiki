About OGS equatorial mount version history:

The OGS equatorial mount has been divided into about 3 versions since its birth:

  • Early Demo version
  • 1.x version
  • 2.x version

At present, we are replicating version 2.x. Other versions are no longer maintained, and their performance and experience are inferior to version 2.0. New versions are under development.

Version 2.x control boards are incompatible with earlier control boards! Don't copy earlier control boards again.

NOTE⚠️:

  • The new version of the reduction gearbox has been modified from a split design to an integrated design, which makes it difficult to install two motor screws. It is recommended to use a longer ball-head 6-angle screwdriver to tighten the screws at an angle.
  • If installation is difficult, only 3 motor fixing screws can be installed
  • All gear fixing screws must be filled with screw glue!
  • If it is difficult to install the optical shaft into the bearing, you can use a rubber hammer to knock it in.
  • The domestic version uses two M5*40 screws (easy to maintain) at the hinge instead of the screws of the foreign version.
